# fitwithRahul - Fitness & Nutrition Planner App

A custom Flutter application built in Dart for **fitwithRahul** clients.

## Key Features
- **Client Calorie & Macro Target Calculator** (BMR via Mifflin-St Jeor + 1.4x activity multiplier)
- **Flexible 3, 4, or 5-Meal Planner** with live macro calculation
- **Indian Whole-Food Database Sheet** (Eggs, Oats, Sprouts, Soya Chunks, Whey, Daal, Dates, Peanut Butter)
- **Branded Hypertrophy Workout Protocol** (10-12 rep range targets)
- **1-Tap WhatsApp PDF Export** with clickable Instagram profile button (`@fitwithRahul`)

## Tech Stack
- **Framework:** Flutter (Dart)
- **Packages:** `pdf`, `printing`, `share_plus`, `path_provider`
